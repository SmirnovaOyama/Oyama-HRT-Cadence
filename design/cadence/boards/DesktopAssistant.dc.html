Step 3 of 3: connect

Run this in your terminal:

claude mcp add oyama -- "/Applications/Oyama Tracker.app/Contents/MacOS/oyama-tracker" --mcp

Then ask something like “What’s my estimated estradiol right now?” The first time, this app asks you to allow it.

Before you connect

With this option nothing is uploaded. Claude Code reads a file on this computer that only your user account can open.

Whatever the assistant reads is sent to the company that runs it, for example Anthropic.

It can’t edit or delete anything. Suggestions wait on your Today page until you add them.

The activity log keeps what was asked and how many items, never the values.
